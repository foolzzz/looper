# 对外动作审查设置验收

本记录覆盖安全设置、无工具分类器角色配置和只读审计；不代表执行过任何真实审查。所有真实成功路径均使用独立 PostgreSQL 数据库、临时 runtime、独立服务端口与合成数据。没有使用活动服务、真实渠道或付费模型。

## 已通过

- 后端定向回归：15 个文件，654 项通过。包含 API 文档、操作级别、角色写入权限、配置导入、钩子、审计查询、围栏及 50 项逐条固定基线校验。没有新增迁移。
- 前端定向回归：12 个文件，263 项通过；新增安全 API、开关及审计的 17 项测试再次通过，构建通过。触屏辅助按钮调整后，4 个相关文件的 41 项测试另行通过。
- 真实 HTTP：operator 读取缺省、两个开关打开/关闭并读回；不兼容 Manager 启用返回 409，保存值保持关闭；分类器 Profile、提示词和超时写入读回；8 类 client 越权请求返回 403；配置导入 staged 文档篡改后 apply 和确认均返回 403；生成 CLI 三个读取操作成功，client 凭据调用角色写入命令得到 forbidden。
- 浏览器真实 API：55 条合成审计按 50/5 分页，跨页 ID 不重复，返回页内容一致；拦截过滤、关联任务的 10 条正向过滤、不存在任务的空结果、展开详情和返回时保留过滤通过。审计仅供展示，没有运行分类器；null 花费和耗时分别显示“未知”和“未记录”。
- 两个开关都先展示本地影响说明；键盘取消不发送更新请求，焦点返回原开关。用户确认后提交，真实 operator 返回 200，保存后读回并关回。202 待确认、原 session 保留和明确第二次确认由前端测试验证，未声称真实 operator 请求必定返回 202。
- 1280 × 1000、390 × 1000、768 × 1000、844 × 390 的设置、审计和展开角色页面均无页面或主内容横向溢出。390 触屏模式使用单列，任务输入占一行且宽度超过 250px，表单文字由全局规则保持 16px，主要按钮和角色辅助按钮至少 44px。Switch 沿用既有扩展触控区域。
- 收尾读回确认两个开关关闭、模型运行记录为0；本次服务、一次性数据库和临时 runtime 已清理。
