# Looper v2.13.119

## Release Decision

**Who should upgrade:** Anyone who reads `loopercli config --help` to find the configuration commands. Others do not need it.

**What this release solves:** [#630](https://github.com/foolzzz/looper/pull/630) gives the handwritten `export` and `import` configuration commands a description line in the `loopercli config` help, so they are listed with descriptions beside the commands generated from the API instead of appearing only in the usage line.

**Breaking changes:** No. No command, option, route, configuration or stored data format changed.

**How to verify:** Check the installed version.

**Contributors:** Maintainer @foolzzz authored [#630](https://github.com/foolzzz/looper/pull/630); no community contribution was included in this patch release.

```bash
looper --version   # looper 2.13.119
```

## Behavior changes

- **Help for `loopercli config`:** in `looper/loopercli.py`, the `export` subcommand now has the help text "Export configuration as JSON to a file or stdout", and `import` has "Preview configuration; request confirmation to apply, or cancel". `config --help` therefore shows a descriptive row for each, as it does for the generated commands (`import-cancel`, `import-upload`, `import-apply`, `import-preview`). Arguments, options and behavior of the commands are unchanged.
- **Model-visible changes:** none. This is CLI help text; no tool declaration, prompt, route or text sent to Workers changed.
- **Tests:** `tests/test_loopercli.py` now requires exactly one descriptive help row per config subcommand (with "export", "configuration" and "json" in the `export` row, and "preview" and "confirmation" in the `import` row), that the token does not appear in the output, and that the fallback help shown when discovery fails also has descriptive `export` and `import` rows. [#630](https://github.com/foolzzz/looper/pull/630) reports added lines: tests 22, production 4 (fixtures excluded).

## Upgrade and rollback

Re-run `install.sh` once v2.13.119 is published. No data migration and no configuration change. Rolling back to v2.13.118 restores the help without descriptions for `export` and `import`.

## Optional Capability Activation & Use

No new optional capability activation is introduced in this release.

- **`loopercli config` 帮助：**`looper/loopercli.py` 中，`export` 子命令新增帮助文字“Export configuration as JSON to a file or stdout”，`import` 新增“Preview configuration; request confirmation to apply, or cancel”。因此 `config --help` 为二者各显示一行说明，与生成的命令（`import-cancel`、`import-upload`、`import-apply`、`import-preview`）一致。命令的参数、选项和行为不变。

- **测试：**`tests/test_loopercli.py` 现在要求每个 config 子命令恰有一行带说明的帮助（`export` 行含 export、configuration、json，`import` 行含 preview、confirmation），输出中不含 token，且发现失败时的回退帮助也有带说明的 `export` 与 `import` 行。[#630](https://github.com/foolzzz/looper/pull/630) 报告新增行数：测试 22、生产代码 4（不含夹具）。
