# Looper v2.14.76

This is the patch release v2.14.76, a hotfix line in which each merged change ships at once. It ships the one change merged since v2.14.75: English copy and clearer directory controls for the project directory move in the dashboard ([#1081](https://github.com/foolzzz/looper/pull/1081)).

## Release Decision

**Who should upgrade:** Operators who use Project → Settings in the dashboard, in particular the directory move added in v2.14.75. Nobody else needs it: there is no backend change.

**What this release solves:** The "Move directory" section was written in Chinese while the rest of the page is English, its target hint could not say which path a move would use, and it was easy to mistake the "Default directory" field (stored path only) for a move of the files. [#1081](https://github.com/foolzzz/looper/pull/1081) fixes the copy and the hints.

**Breaking changes:** No. The change is dashboard text and one disabled-button rule; no API, operation, schema or setting changes.

**How to verify:** Check the installed version.

**Contributors:** Maintainer @foolzzz authored [#1081](https://github.com/foolzzz/looper/pull/1081); no community contribution was included in this release.

```bash
looper --version   # looper 2.14.76
```

## Upgrading

The bridge boundary is unchanged: an installation older than v2.13.165 must upgrade to v2.13.165 first (upgrade to v2.13.165 first) and be started once; see the Upgrading section of the v2.14.0 release for the steps and rollback. An installation on v2.14.0 to v2.14.75 upgrades directly. This release has no schema change.

## Behavior changes

- **Dashboard copy.** In Project → Settings the "Move directory" section (heading, description, labels, the link switch, notices, result lines and buttons) is in English instead of Chinese (`web/src/components/project-settings.tsx`).
- **Target hint.** The target field's placeholder is `Leave empty for a new directory under <root>` when `[projects] root` is set, and `/absolute/path` otherwise. It does not name one exact path, because the server picks the first free `<root>/<name>`, `<root>/<name>-2`, …. The project page passes the root it already loads to the form (`web/src/pages/project.tsx`).
- **Preview disabled without a target.** Without a projects root, the Preview button stays disabled while the target field is empty. With a root, an empty target is still allowed.
- **Description.** It says that anything in progress in the project (a task step, a schedule run or a gate) blocks the move and that the preview says what.
- **Default directory hint.** Under "Default directory": "Changes the stored path only; files stay where they are. To move the files, use Move directory below."
- **No backend change.** Three files change (two dashboard source files and one test file), about 92 added and 39 removed lines, of which 70 added lines are tests.
- **Model-visible changes:** None. No tool description or schema, role text or prompt changes.

### 升级决策

**谁需要升级：**使用控制台项目 → 设置的运维人员，尤其是使用 v2.14.75 新增目录移动的人。其他人无需升级：没有后端变更。

**是否有破坏性变更：**否。本改动只涉及控制台文本和一条按钮禁用规则；API、操作、数据库结构和设置均无变化。

### 升级

桥接边界不变：早于 v2.13.165 的安装必须先升级到 v2.13.165 并启动一次（upgrade to v2.13.165 first 即先升级到 v2.13.165），步骤与回退见 v2.14.0 发布说明的升级一节。v2.14.0 至 v2.14.75 上的安装可直接升级。本版本没有数据库结构变更。

### 行为变化与入口

- **控制台文案。**项目 → 设置中的「Move directory」区块（标题、说明、标签、链接开关、提示、结果行和按钮）由中文改为英文（`web/src/components/project-settings.tsx`）。
- **目标提示。**设置了 `[projects] root` 时，目标输入框占位符为 `Leave empty for a new directory under <root>`，否则为 `/absolute/path`。它不指明某一个确切路径，因为服务器会选第一个空闲的 `<root>/<name>`、`<root>/<name>-2` ……。项目页把已加载的根目录传给表单（`web/src/pages/project.tsx`）。
- **无目标时禁用预览。**没有 projects root 且目标为空时，预览按钮保持禁用；有 root 时仍允许留空。
- **说明。**说明指出项目中任何进行中的内容（任务步骤、定时任务运行或 gate）会阻止移动，预览会说明具体是什么。
- **默认目录提示。**「Default directory」下方说明：只修改存储的路径，文件留在原处；要移动文件请使用下方的 Move directory。
- **无后端变更。**共改动三个文件（两个控制台源文件和一个测试文件），约新增 92 行、删除 39 行，其中 70 行新增为测试。
- **面向模型的变化：**无。没有工具说明或 schema、角色文本或提示词变化。
