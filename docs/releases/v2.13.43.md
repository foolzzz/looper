# Looper v2.13.43

## Release Decision

**Who should upgrade:** No one needs to. This release changes tests and CI only; the installed program is the same as v2.13.42 apart from its version number.

**What this release solves:** [#416](https://github.com/foolzzz/looper/pull/416) slims the test suite (step pr2): the migration-era launch snapshots drop their prompt text, and the harness self-tests and the fixtures only they used are removed.

**Breaking changes:** No. Nothing under `looper/` changed.

**How to verify:** Check the installed version.

**Contributors:** Maintainer @foolzzz authored [#416](https://github.com/foolzzz/looper/pull/416); no community contribution was included in this patch release.

```bash
looper --version   # looper 2.13.43
```

## Behavior changes

- **Runtime behavior:** none. The pull request touches no file under `looper/`, and its description states "Behavior changes: none".
- **Tests** (`tests/`): the four `model_launch_parity_v2_*.json` fixtures are rewritten without the migration-era prompt text. `agent_launch_parity_main.json`, `profile_rename_parity_main.json`, `system_prompt_append.json`, `test_agent_launch_parity_db.py` and `test_llm_registry_v2_seed_db.py` are deleted. The harness helpers (`agent_launch_parity.py`, `model_launch_parity.py`, `profile_rename_parity.py`) and the capture, parity, recovery, rehearsal, prompt-preview and system-prompt tests are trimmed to match.
- **CI** (`.github/workflows/`): a new workflow `launch-provenance.yml` runs the tests marked `provenance` (they clone an old revision to prove where a pinned fixture came from) on a daily schedule, on manual dispatch, and on pull requests that touch the launch fixtures or their harness. `python-tests.yml` now runs the main suite with `-m "not provenance"`, and its checkout comment says the recovery tests archive the supported v2.12 source. `pyproject.toml` registers the `provenance` pytest marker.
- **Changelog:** the CHANGELOG line "Supported upgrades start at v2.12" moves from Unreleased into this release.
- **Model-visible changes:** none. No prompt text, tool description, tool schema or `Channel:` line changed; the prompt text removed is stored in test fixtures only.

## Upgrade and rollback

Re-run `install.sh` once v2.13.43 is published. There is no schema change and no data migration. Rolling back to v2.13.42 needs no step.

## Optional Capability Activation & Use

No new optional capability activation is introduced in this release.
