# Looper v2.13.124

## Release Decision

**Who should upgrade:** Nobody needs to upgrade for behavior. This patch release only carries a documentation change.

**What this release solves:** [#643](https://github.com/foolzzz/looper/pull/643) marks the insecure-context dashboard fix as done in the development plan, so the plan no longer lists it as open.

**Breaking changes:** No. No command, option, route or schema changed.

**How to verify:** Check the installed version.

**Contributors:** Maintainer @foolzzz authored [#643](https://github.com/foolzzz/looper/pull/643); no community contribution was included in this patch release.

```bash
looper --version   # looper 2.13.124
```

## Behavior changes

- **None.** The merged diff changes one line in `docs/plans/2026-10-13-long-horizon-agent-context.zh-CN.md` (section 5.1): the entry for the dashboard blank page in insecure contexts is struck through and marked as fixed, and it now says that id generation falls back to `crypto.getRandomValues` there. The fix itself shipped earlier; this release changes no code.
- **Model-visible changes:** none. Prompts, tool declarations and results are unchanged.
- **Line counts:** the description of [#643](https://github.com/foolzzz/looper/pull/643) reports tests 0 and production 0; the merged diff is 1 added and 1 removed line in 1 file.

## Upgrade and rollback

Re-run `install.sh` once v2.13.124 is published, or stay on v2.13.123; the two behave the same. No configuration change. Rolling back is harmless.

## Optional Capability Activation & Use

No new optional capability activation is introduced in this release.

## Validation

**Retained implementation evidence:** the description of [#643](https://github.com/foolzzz/looper/pull/643) says only "the tests that cover the change; automated reviews; CI before the merge". It gives no counts or verdicts, and no local full-suite result is recorded for it. This draft did not re-run any of it.

**CI:** CI runs after the release is drafted; its result is not recorded here.

**Not tested for this draft:** Local test runs, a local full suite, a live service. The release documentation gate checks the body only.
