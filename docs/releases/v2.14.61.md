# Looper v2.14.61

This is the patch release v2.14.61, a hotfix line in which each merged change ships at once. It ships the one change merged since v2.14.60: the lost-lock restart test now ends the system pool's own connection too ([#1045](https://github.com/foolzzz/looper/pull/1045)). The change is test-only.

## Release Decision

**Who should upgrade:** No one needs to upgrade for behavior. This release changes a test only; it is for maintainers and anyone who builds from a tag and wants the test suite to match.

**What this release solves:** `test_a_database_restart_is_a_lost_lock` simulates a database restart by ending every connection except an exemption set taken before startup. That set also held the connection of the fixture's pool, which the test reuses as the system's pool, so the "restart" left a system connection open and the later fence, which closes the pool itself, hid the gap in coverage. [#1045](https://github.com/foolzzz/looper/pull/1045) takes the pool's connection out of the exemption and asserts that the restart ends every connection the system holds: the pool's connection made before startup, the lease's, and all opened later. The exemption keeps only the schema administrator and unrelated connections. A test that again exempts a system connection now fails.

**Breaking changes:** No. No production code, API or configuration changes and there is no migration.

**How to verify:** Check the installed version.

**Contributors:** Maintainer @foolzzz authored [#1045](https://github.com/foolzzz/looper/pull/1045); no community contribution was included in this release.

```bash
looper --version   # looper 2.14.61
```

### 升级决策

**谁需要升级：**行为上无人必须升级。本版本只改动测试，面向维护者以及从标签构建、希望测试套件保持一致的用户。

**解决了什么：**`test_a_database_restart_is_a_lost_lock` 通过结束除启动前豁免集合之外的所有连接来模拟数据库重启。该集合同时包含夹具连接池的连接，而测试把它复用为系统的连接池，因此“重启”留下了一个系统连接，之后关闭连接池本身的屏障掩盖了这一覆盖缺口。[#1045](https://github.com/foolzzz/looper/pull/1045) 把连接池的连接移出豁免，并断言重启会结束系统持有的所有连接：启动前建立的连接池连接、租约的连接，以及之后打开的全部连接。豁免只保留 schema 管理员和无关连接。再次豁免系统连接的测试会失败。

**是否有破坏性变更：**否。没有生产代码、API 或配置变更，也没有迁移。

**如何验证：**运行 `looper --version` 核对版本为 2.14.61。

**贡献者：**维护者 @foolzzz 提交 [#1045](https://github.com/foolzzz/looper/pull/1045)；本版本无社区贡献。
