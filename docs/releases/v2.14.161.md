# Looper v2.14.161

This is the patch release v2.14.161, a hotfix line in which each merged change ships at once. It documents one change: [#1291](https://github.com/foolzzz/looper/pull/1291) (README refresh).

## Release Decision

**Who should upgrade:** Nobody needs to upgrade for behavior. This release only updates the README files; upgrade to keep the version number in step with `main`.

**What this release solves:** [#1291](https://github.com/foolzzz/looper/pull/1291) makes `README.md` and `README.zh-CN.md` describe Looper as it is now and aligns the first screen with the repository description: a self-hosted, planner-driven multi-agent system for orchestrating coding agents.

**Breaking changes:** No. There is no code change, API change, migration or schema change. The bridge boundary is unchanged: upgrade to v2.13.165 first if the installation is older.

**How to verify:** Check the installed version.

```bash
looper --version   # looper 2.14.161
```

**Contributors:** Maintainer @foolzzz authored [#1291](https://github.com/foolzzz/looper/pull/1291); no community contribution was included in this release.

## Upgrading

The bridge boundary is unchanged: an installation older than v2.13.165 must upgrade to v2.13.165 first (upgrade to v2.13.165 first) and be started once; see the Upgrading section of the v2.14.0 release for the steps and rollback. An installation on v2.14.0 to v2.14.160 upgrades directly. There is no schema change.

## Behavior changes

There are none. The pull request changes only `README.md` (162 additions, 92 deletions) and `README.zh-CN.md` (87 additions, 69 deletions), and states "Documentation only; no behavior change." No Python, web or script file is touched.

- **README content.** The tagline and the "What is Looper" text and diagram describe the Manager (dashboard chat, Lark, Telegram, CLI/API), one Planner per task, and Workers and Reviewers on the agent runtime of their Agent Profile. Key features are regrouped into twelve items; the quick start names `install.sh` as the main install path and asks for at least one signed-in agent runtime. Statements that no longer matched the code are corrected: the architecture table, channels, runtime list, Settings pages, dashboard table, restarting cancelled tasks, and the backup example. The Chinese README mirrors the English one.
- **Spot check for this draft.** The channels (web, Lark, Telegram) and runtimes named in the README exist under `looper/agents/channels` and `looper/agents/runtimes`; `install.sh`, `docs/architecture/agent-system.md` and the `loopercli` entry point exist. This is not a line-by-line audit of the README.
- **Model-visible changes:** None. No prompt, tool description, schema or answer text changes.
