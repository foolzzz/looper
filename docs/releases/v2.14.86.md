# Looper v2.14.86

This is the patch release v2.14.86, a hotfix line in which each merged change ships at once. It ships the one change merged since v2.14.85: the dashboard now shows the TTADK rows and the Cursor Agent runtime, and warns that Cursor runs use the operator's own login and configuration ([#1107](https://github.com/foolzzz/looper/pull/1107)).

## Release Decision

**Who should upgrade:** Operators who use the TTADK rows or the Cursor Agent runtime and want the dashboard to show them correctly. Everyone else can stay.

**What this release solves:** The Agent Runtimes page did not name the TTADK rows, did not say that Cursor Agent runs use the operator's own Cursor login and `HOME`, and the top banner did not show the `cursor_login` and `ttadk` doctor failures. [#1107](https://github.com/foolzzz/looper/pull/1107) adds these without new forms.

**Breaking changes:** No. No setting, operation, field or database column changes. The change is in the dashboard only.

**How to verify:** Check the installed version. In Settings → Agent Runtimes, the Cursor Agent card states that its runs use your own Cursor login and HOME and that your personal Cursor and Claude Code configuration applies and cannot be turned off; TTADK rows show their row name and a TTADK badge.

**Contributors:** Maintainer @foolzzz authored [#1107](https://github.com/foolzzz/looper/pull/1107); no community contribution was included in this release.

```bash
looper --version   # looper 2.14.86
```

## Upgrading

The bridge boundary is unchanged: an installation older than v2.13.165 must upgrade to v2.13.165 first (upgrade to v2.13.165 first) and be started once; see the Upgrading section of the v2.14.0 release for the steps and rollback. An installation on v2.14.0 to v2.14.85 upgrades directly. There is no database change.

## Behavior changes

- **Agent Runtimes page** (`web/src/components/runtime-cards.tsx`, `web/src/lib/runtime-catalog.ts`). Runtime rows with the TTADK launcher are listed after the built-in runtimes, titled by their row name (for example `ttadk-codex`, `ttadk-cursoragent`) and marked with a TTADK badge. The Cursor Agent type has a catalog entry ("Cursor CLI") with its install command.
- **Cursor Agent card.** For a runtime type that loads the operator's configuration (`loads_operator_config`), the card says: runs use your own Cursor login and HOME, so your personal Cursor and Claude Code configuration (rules, hooks, MCP servers, skills, plugins) applies and cannot be turned off.
- **Top banner** (`web/src/components/claude-check-banner.tsx`). It also shows failed `cursor_login` and `ttadk` doctor checks, in addition to the Claude, Codex and Grok ones.
- **Agent Profile runtime dropdown** (`web/src/components/agent-profiles.tsx`, `web/src/lib/api.ts`). Whether a model can pair with a runtime now uses the authentication kinds of that runtime row (`auth_kinds`, computed by the server and read by the dashboard) instead of those of its type, so TTADK rows pair according to what their launcher accepts. The dropdown lists row names as before.
- **Unchanged:** `loopercli`, the Manager's tools (they take `runtime_id`), the server, the API, the database, and wheel and source upgrades.
- **Documentation and tests.** The pull request adds a headless-browser test of the Agent Runtimes page (`tests/test_runtime_cards_browser.py`) and updates the dashboard unit tests of the runtime cards, Agent Profiles and the banner.
- **Model-visible changes:** None. No prompt, tool text or tool result changes.

**如何验证：**核对版本为 2.14.86。在 设置 → Agent Runtimes 中，Cursor Agent 卡片说明其运行使用你自己的 Cursor 登录和 HOME，个人的 Cursor 与 Claude Code 配置会生效且无法关闭；TTADK 行显示行名称和 TTADK 徽标。

**贡献者：**维护者 @foolzzz 提交 [#1107](https://github.com/foolzzz/looper/pull/1107)；本版本无社区贡献。

### 升级

桥接边界不变：早于 v2.13.165 的安装必须先升级到 v2.13.165 并启动一次（upgrade to v2.13.165 first 即先升级到 v2.13.165），步骤与回退见 v2.14.0 发布说明的升级一节。v2.14.0 至 v2.14.85 上的安装可直接升级。没有数据库变更。

### 行为变化与入口

- **Agent Runtimes 页面**（`web/src/components/runtime-cards.tsx`、`web/src/lib/runtime-catalog.ts`）。使用 TTADK 启动器的运行时行列在内置运行时之后，以行名称（如 `ttadk-codex`、`ttadk-cursoragent`）为标题并带 TTADK 徽标。Cursor Agent 类型有了目录条目（"Cursor CLI"）及安装命令。
- **Cursor Agent 卡片。**对加载运维人员配置的运行时类型（`loads_operator_config`），卡片说明：运行使用你自己的 Cursor 登录和 HOME，因此你个人的 Cursor 与 Claude Code 配置（规则、hooks、MCP 服务器、skills、插件）会生效且无法关闭。
- **顶部横幅**（`web/src/components/claude-check-banner.tsx`）。除 Claude、Codex、Grok 外，也显示失败的 `cursor_login` 与 `ttadk` 自检。
- **Agent Profile 运行时下拉**（`web/src/components/agent-profiles.tsx`、`web/src/lib/api.ts`）。模型能否与运行时配对，现在使用该运行时行的认证类型（`auth_kinds`，由服务器计算、仪表盘读取），而不是其类型的认证类型，因此 TTADK 行按其启动器接受的方式配对。下拉仍列出行名称。
- **不变：**`loopercli`、管家的工具（它们使用 `runtime_id`）、服务器、API、数据库，以及 wheel 与源码升级。
- **文档与测试。**该 PR 新增 Agent Runtimes 页面的无头浏览器测试（`tests/test_runtime_cards_browser.py`），并更新了运行时卡片、Agent Profiles 和横幅的仪表盘单元测试。
- **面向模型的变化：**无。提示、工具文本和工具结果均不变。
