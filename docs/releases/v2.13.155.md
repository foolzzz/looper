# Looper v2.13.155

## Release Decision

**Who should upgrade:** No one needs to. This patch changes only a test; the installed program is the same as v2.13.154. Everyone can stay on v2.13.154.

**What this release solves:** [#718](https://github.com/foolzzz/looper/pull/718) makes the test that checks request deadlines on the `api` runtime reliable and stricter. Its subject says a deadline that fires while the OpenAI SDK is retrying ends the turn with the typed timeout outcome instead of a leaked `asyncio.CancelledError`; the pull request changes no production code, so that outcome is only checked here, not changed.

**Breaking changes:** No. There is no production change.

**How to verify:** Check the installed version.

**Contributors:** Maintainer @foolzzz authored [#718](https://github.com/foolzzz/looper/pull/718); no community contribution was included in this patch release.

```bash
looper --version   # looper 2.13.155
```

## Behavior changes

- **None at runtime (#718):** the pull request touches only `tests/test_api_responses.py` (13 lines added, 2 removed). `looper/agents/runtimes/api/responses.py` and `loop.py` are unchanged.
- **Deadline test (#718):** `test_deadlines_abort_io_and_close_server_connections` now runs a warm-up turn first, so lazy SDK imports and schema setup finish before the short deadline applies; the deadline is 0.2 seconds instead of 0.05. It also asserts, for each deadline, that the turn fails with `ErrorKind.UNAVAILABLE`, that the number of requests the fake server saw equals the number of recorded requests, that no history, tool call or `RequestDone` event was produced, and, for the SDK retry case, that the recorded request has status 503 and zero retries.
- **Model-visible changes:** none. No prompts, tool descriptions or schemas change.
- **Docs:** none besides this release's notes and the CHANGELOG entry.

## Upgrade and rollback

Re-run `install.sh` once v2.13.155 is published if you want the version number to match; behavior is identical. Rolling back to v2.13.154 changes nothing at runtime.
