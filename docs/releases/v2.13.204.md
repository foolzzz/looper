# Looper v2.13.204

## Release Decision

**Who should upgrade:** Maintainers who build from the source tree. This release only removes unused code and tests; an installed service behaves the same. It ships the change merged since v2.13.203.

**What this release solves:** [#855](https://github.com/foolzzz/looper/pull/855) deletes the unused registry preflight and converter module `looper/agents/registry_migration.py` together with its test file and one test that only exercised the layer-effort converter.

**Breaking changes:** No. Commands, settings, the database schema and the admitted upgrade path are unchanged.

**How to verify:** Check the installed version.

**Contributors:** Maintainer @foolzzz authored [#855](https://github.com/foolzzz/looper/pull/855); no community contribution was included in this patch release.

```bash
looper --version   # looper 2.13.204
```

## Behavior changes

- **Removed code (`looper/agents/registry_migration.py`):** the module (720 lines) is deleted. A search of `looper` and `tests` finds no remaining import of it; the only mentions are the retired-module checks in `tests/test_bridge_schema_db.py`, which refer to `looper.db.registry_migration` (already removed in v2.13.203).
- **Removed tests:** `tests/test_registry_migration.py` (872 lines) is deleted, and `test_derived_profile_identity_and_insert_preserve_custom_prompt` is removed from `tests/test_custom_prompt.py` together with its `layer_effort` import. The other tests in that file are unchanged.
- **Not removed, despite the description:** the description of #855 names `looper/agents/layer_effort.py` and `tests/test_layer_effort.py` and seven historical fixtures as deleted. The merged diff touches only three files (1614 lines deleted, none added): both layer-effort files are still present, and no fixture file was deleted. This release therefore does not remove them. The description's own counts (about 22600 lines deleted) do not match the merged change either.
- **Runtime behavior:** none. No production code outside the deleted module changed, and nothing imports it.
- **Model-visible changes:** None. No prompt, tool or message text changed.

## Upgrade and rollback

Re-run `install.sh` once v2.13.204 is published. No data or schema change is involved, so a rollback to v2.13.203 needs no database restore.

## Optional Capability Activation & Use

No new optional capability activation is introduced in this release.

## Validation

**Retained implementation evidence:** the description of [#855](https://github.com/foolzzz/looper/pull/855) lists the covering tests (`tests/test_custom_prompt.py`, the agent settings, profile registry, runtime signature, LLM registry and provider, database backup, bridge schema, config import and transfer, provider binding, current-tier launch, and channel bot suites), automated reviews and CI before the merge. It records no counts, verdicts or local full-suite result.

**CI:** CI runs after the release is drafted; its result is not recorded here.

**Not tested for this draft:** Local test runs, a local full suite, a live service, a browser run and the built wheel. The release documentation gate checks the body only.

### 行为变化与入口

- **删除的代码（`looper/agents/registry_migration.py`）：**删除该模块（720 行）。在 `looper` 和 `tests` 中搜索，已无对它的导入；仅有的提及是 `tests/test_bridge_schema_db.py` 中对已退役模块 `looper.db.registry_migration`（v2.13.203 已删除）的检查。
- **删除的测试：**删除 `tests/test_registry_migration.py`（872 行），并从 `tests/test_custom_prompt.py` 删除 `test_derived_profile_identity_and_insert_preserve_custom_prompt` 及其 `layer_effort` 导入；该文件其余测试不变。
- **描述与实际不符：**#855 的描述称删除了 `looper/agents/layer_effort.py`、`tests/test_layer_effort.py` 和七个历史夹具。实际合并的差异只涉及三个文件（删除 1614 行，无新增）：两个 layer-effort 文件仍然存在，也没有夹具文件被删除。因此本版本并未删除它们。描述中约 22600 行删除的数字同样与合并结果不符。
- **运行时行为：**无变化。被删模块之外没有生产代码改动，也没有代码导入它。
- **面向模型的变化：**无。提示词、工具和消息文本均未改变。

### 升级与回退
