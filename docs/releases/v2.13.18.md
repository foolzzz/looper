# Looper v2.13.18

## Release Decision

**Who should upgrade:** Anyone who answers gates or chats with Looper through a chat channel (Telegram, Lark or the web channel). Everyone else sees no change.

**What this release solves:** [#344](https://github.com/foolzzz/looper/pull/344) adds command hints on every channel. A gate card that asks for a decision now names `/gates`, `/gate` and how to end the discussion. `/help` is answered by Looper itself on every channel, from the one command list that Telegram's command menu also reads, instead of only on Telegram.

**Breaking changes:** No. No CLI command, configuration key, API or database schema changed.

**How to verify:** Check the installed version.

**Contributors:** Maintainer @foolzzz authored [#344](https://github.com/foolzzz/looper/pull/344); no community contribution was included in this patch release.

```bash
looper --version   # looper 2.13.18
```

## Behavior changes

- **Gate cards:** the "needs your decision" card and the reminder card end with one more line: `/gates 查看所有等你回答的关卡；/gate 编号 回答，/gate 编号 end 结束讨论`. The updated, cancelled and closed cards are unchanged. The change is in `looper/agents/gate_courier.py`.
- **`/help` on every channel:** the Manager recognises `/help` (and Telegram's `/help@bot`, case-insensitively) and replies with the shared help text without calling the model. The user's `/help` message is stored in the session like other commands. The change is in `looper/agents/tiers/manager.py`.
- **One command list:** the new `looper/agents/chat_commands.py` holds the commands, their descriptions and the help text. Telegram's command menu and Telegram's `/help` read it, and `/stop` is listed only while `chat.stop_enabled` is on, as before for the menu. The Telegram `/help` text is now headed `Looper 命令：` (it was `Looper Agent 命令:`) and, like the menu, omits `/stop` while stopping a reply is off; before, it always listed `/stop`.
- **Model-visible changes:** None to prompts, tool schemas or tool results. `/help` no longer reaches the model on non-Telegram channels. The gate card text is posted to chat, not into a model prompt.

## Upgrade and rollback

Re-run `install.sh` once v2.13.18 is published. There is no schema or configuration change. Rolling back to v2.13.17 is safe.

## Optional Capability Activation & Use

No new optional capability activation is introduced in this release.

### 行为变化与入口

- 关卡卡片：“需要你决定”卡片与提醒卡片末尾多一行：`/gates 查看所有等你回答的关卡；/gate 编号 回答，/gate 编号 end 结束讨论`。更新、取消、关闭卡片不变。改动在 `looper/agents/gate_courier.py`。
- 所有渠道的 `/help`：Manager 识别 `/help`（以及 Telegram 的 `/help@bot`，不区分大小写），不经模型直接回复共享帮助文本；用户的 `/help` 消息与其他命令一样记入会话。改动在 `looper/agents/tiers/manager.py`。
- 统一命令列表：新增 `looper/agents/chat_commands.py`，集中命令、描述与帮助文本。Telegram 命令菜单与 Telegram 的 `/help` 都读取它；仅当 `chat.stop_enabled` 开启时才列出 `/stop`（此前只有菜单如此）。Telegram `/help` 的标题由 `Looper Agent 命令:` 改为 `Looper 命令：`，且停止回复关闭时不再列出 `/stop`（此前总是列出）。
- 面向模型的变化：提示词、工具 schema、工具结果均无变化。非 Telegram 渠道的 `/help` 不再到达模型。关卡卡片文本发到聊天，不进入模型提示词。
