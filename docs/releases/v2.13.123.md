# Looper v2.13.123

## Release Decision

**Who should upgrade:** Dashboard users who restart tasks, in particular a task that was stopped or whose earlier run records are stale.

**What this release solves:** [#633](https://github.com/foolzzz/looper/pull/633) makes the task page confirm a completed restart from a new per-task attempt end marker instead of the lifetime run count and completion time, which a stale historical run record could confuse.

**Breaking changes:** No. No command, option or route changed. One nullable column and one nullable field in the task detail result are added.

**How to verify:** Check the installed version.

**Contributors:** Maintainer @foolzzz authored [#633](https://github.com/foolzzz/looper/pull/633); no community contribution was included in this patch release.

```bash
looper --version   # looper 2.13.123
```

## Behavior changes

- **New stored column:** `looper/db/schema.sql` adds `tasks.attempt_ended_at` (nullable timestamp) with `ADD COLUMN IF NOT EXISTS`, so it is applied on startup. Existing tasks keep it NULL (unknown); startup does not invent end times.
- **When it is set and cleared:** `update_task_status` in `looper/db/tasks.py` sets it whenever a task becomes `completed`, `failed`, `cancelled` or `stopped`; other statuses leave it unchanged. `mark_orphaned_tasks_stopped` sets it when it stops orphaned active tasks. `reset_task_for_restart` clears it to NULL.
- **API result:** `task_detail` returns `attempt_ended_at`, and the task-detail schema (`TASK_DETAIL`) and the dashboard's `TaskDetail` type declare it as a nullable string.
- **Dashboard:** in `web/src/pages/task-detail.tsx` the restart confirmation now treats the restart as changed when the status differs or `attempt_ended_at` is set and differs from its value before the restart. It counts as settled when the marker is new, or when no run is reported as running. A terminal state must be seen twice with the same status, marker and run count before it is accepted. A Stop is recognised, since it leaves `completed_at` empty. Run counts alone no longer signal a new attempt.
- **Tests:** new coverage in `tests/test_task_detail_db.py`, `tests/test_task_activity_restart_browser.py` and `web/src/pages/task-detail-route.test.tsx`; two migration tests (`test_llm_registry_rehearsal_db.py`, `test_profile_rename_migration_db.py`) now expect the new column to stay NULL for old rows.
- **Model-visible changes:** none to prompts or tool declarations. The `task_detail` result, which agents can read, gains the `attempt_ended_at` field.
- **Line counts:** the description of [#633](https://github.com/foolzzz/looper/pull/633) reports tests 104 and production 75 (fixtures excluded); the merged diff is 272 added and 17 removed lines over 11 files.

## Upgrade and rollback

Re-run `install.sh` once v2.13.123 is published. The schema change is additive and applied on startup; no configuration change. Rolling back to v2.13.122 leaves the extra column unused and harmless.

### 升级决策

**谁需要升级：**会在仪表盘重启任务的用户，尤其是被停止的任务，或历史运行记录已过期的任务。

**解决了什么：**[#633](https://github.com/foolzzz/looper/pull/633) 让任务页用新的“本次尝试结束时间”标记来确认重启已完成，而不再依赖累计运行次数和完成时间，后者可能被过期的历史运行记录混淆。

**是否有破坏性变更：**否。命令、选项和路由均未改变。仅新增一个可空列和任务详情结果中的一个可空字段。

**如何验证：**运行 `looper --version` 核对版本为 2.13.123。

**贡献者：**维护者 @foolzzz 提交 [#633](https://github.com/foolzzz/looper/pull/633)；本次 patch release 无社区贡献。

```bash
looper --version   # looper 2.13.123
```

### 行为变化与入口

- **新增存储列：**`looper/db/schema.sql` 用 `ADD COLUMN IF NOT EXISTS` 新增可空时间戳列 `tasks.attempt_ended_at`，启动时自动应用。已有任务保持 NULL（未知），启动时不会伪造结束时间。
- **设置与清除时机：**`looper/db/tasks.py` 中的 `update_task_status` 在任务变为 `completed`、`failed`、`cancelled` 或 `stopped` 时设置该列，其他状态不改动；`mark_orphaned_tasks_stopped` 停止孤儿任务时也会设置；`reset_task_for_restart` 将其清为 NULL。
- **API 结果：**`task_detail` 返回 `attempt_ended_at`，任务详情 schema（`TASK_DETAIL`）和仪表盘的 `TaskDetail` 类型将其声明为可空字符串。
- **仪表盘：**`web/src/pages/task-detail.tsx` 的重启确认现在在状态变化，或 `attempt_ended_at` 已设置且与重启前不同的时候，认为已变化；标记为新值，或没有运行被报告为进行中时，认为已稳定。终态必须以相同的状态、标记和运行次数连续出现两次才被接受。Stop 会被识别（此时 `completed_at` 为空）。仅靠运行次数不再作为新尝试的信号。
- **测试：**`tests/test_task_detail_db.py`、`tests/test_task_activity_restart_browser.py` 和 `web/src/pages/task-detail-route.test.tsx` 新增覆盖；两个迁移测试（`test_llm_registry_rehearsal_db.py`、`test_profile_rename_migration_db.py`）现在期望旧行的新列保持 NULL。
- **面向模型的变化：**提示词和 tool 声明无变化。agent 可读取的 `task_detail` 结果新增 `attempt_ended_at` 字段。
- **行数：**[#633](https://github.com/foolzzz/looper/pull/633) 的描述报告测试 104、生产代码 75（不含夹具）；合并后的差异为 11 个文件、新增 272 行、删除 17 行。
