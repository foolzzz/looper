# Looper v2.13.147

## Release Decision

**Who should upgrade:** Operators who use the dashboard's Settings → Agent Profiles and run a Looper where an in-process runtime such as Model API (SDK) is unavailable. Everyone else can stay on v2.13.146.

**What this release solves:** [#700](https://github.com/foolzzz/looper/pull/700) (covers #698) shows the probe error, including the reinstall hint, for such a runtime instead of the misleading "not on the server's PATH" wording.

**Breaking changes:** No. Only the dashboard component changes; the API, exports and stored data are unchanged.

**How to verify:** Check the installed version.

**Contributors:** Maintainer @foolzzz authored [#700](https://github.com/foolzzz/looper/pull/700); no community contribution was included in this patch release.

```bash
looper --version   # looper 2.13.147
```

## Behavior changes

- **Runtime option hint (#700):** in `web/src/components/agent-profiles.tsx`, a disabled (undetected) runtime option now takes its hint from the runtime type: for an in-process runtime it is the type's `probe_error`, or "not available" when that is empty; for any other runtime it stays "not on the server's PATH". The hint is shown in the option text and as its `title` tooltip.
- **Layout (#700):** the Runtime field and its select get `min-w-0`, and the select gets `truncate`, so a long probe error no longer widens the form.
- **Tests (#700):** `web/src/components/agent-profiles.test.tsx` adds two tests (23 lines): an unavailable in-process runtime is disabled and shows the package probe error without "PATH", with the same text as its title; an unavailable CLI runtime keeps the PATH hint and does not show its probe error.
- **Model-visible changes:** none. No prompt, tool declaration or tool result changes; no Python code changes.
- **Line counts:** the description reports tests 0 and production 33 added lines, but its file list shows 23 added test lines and 10 added production lines. This draft reports the file list.

## Upgrade and rollback

Re-run `install.sh` once v2.13.147 is published. No schema migration. Rolling back to v2.13.146 brings back the PATH wording for an unavailable in-process runtime; stored data is unaffected.

## Optional Capability Activation & Use

No new optional capability activation is introduced in this release.

### 行为变化与入口

- **Runtime 选项提示（#700）：**`web/src/components/agent-profiles.tsx` 中不可用（未检测到）的 runtime 选项，其提示取决于 runtime 类型：进程内 runtime 显示该类型的 `probe_error`，为空时显示 “not available”；其他 runtime 仍显示 “not on the server's PATH”。提示同时出现在选项文本和 `title` 提示中。
- **布局（#700）：**Runtime 字段及其 select 增加 `min-w-0`，select 增加 `truncate`，过长的探测错误不再撑宽表单。
- **测试（#700）：**`web/src/components/agent-profiles.test.tsx` 新增两个测试（23 行）：不可用的进程内 runtime 被禁用，显示包探测错误且不含 “PATH”，title 与之相同；不可用的 CLI runtime 保留 PATH 提示，不显示其探测错误。
- **面向模型的变化：**无。提示词、tool 声明和工具结果均不变；无 Python 代码变更。
- **行数：**描述报告新增测试 0 行、生产代码 33 行，但其文件列表显示新增测试 23 行、生产代码 10 行。本草稿以文件列表为准。
