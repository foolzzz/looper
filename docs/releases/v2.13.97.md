# Looper v2.13.97

## Release Decision

**Who should upgrade:** Anyone who runs agent turns that are stopped or ended while their process tree changes, where a process id may be reused by an unrelated process during the turn.

**What this release solves:** [#560](https://github.com/foolzzz/looper/pull/560) rejects reused process identities before every refresh of a turn's process tree. Before, a pid whose start time had changed was only excluded at the end of a turn, so a refresh in between could adopt the replacement process's subtree or group, and ending the turn could signal it.

**Breaking changes:** No. No API, configuration, prompt or Tool declaration changed.

**How to verify:** Check the installed version.

**Contributors:** Maintainer @foolzzz authored [#560](https://github.com/foolzzz/looper/pull/560); no community contribution was included in this patch release.

```bash
looper --version   # looper 2.13.97
```

## Behavior changes

- **Process identity checks ([#560](https://github.com/foolzzz/looper/pull/560)):** in `looper/agents/proc_tree.py`, `TurnTree.refresh` now calls `_reused` against the fresh process table before it expands the tree, and drops excluded pids from the remembered process groups. A pid whose start time differs from the one first observed is recorded in a new `_excluded` set and stays excluded for the rest of the turn. `TurnTree.track` now reads start times when the turn starts, so the initial identities exist from the first moment.
- **Identities that cannot be proven:** a pid whose start time was never read, or that no longer appears in the start-time table, is excluded for that observation rather than being given a later process's start time. When start times cannot be read at all, every seen pid and the agent's own pid are excluded. A reaped root with a recorded identity still owns its surviving group.
- **End of a turn:** `TurnTree.end` now refreshes first and then computes the exclusions, instead of excluding before the refresh. When the agent's own pid has no identity, `_end_all` signals only the live subprocess handle (SIGTERM, then SIGKILL after the grace period) and never infers a group from the pid.
- **Unchanged:** processes with a proven identity are ended as before; the other channels, the dashboard and the stop flow are unchanged.
- **Model-visible changes:** none for prompts, Tool declarations and Tool results.
- **Tests:** `tests/test_proc_tree.py` adds cases for reused identities across refreshes, unreadable identities, a reaped root and the handle-only fallback. [#560](https://github.com/foolzzz/looper/pull/560) reports 163 test lines and 32 production lines added.

## Upgrade and rollback

Re-run `install.sh` once v2.13.97 is published. No data migration and no configuration change. Rolling back to v2.13.96 restores the previous behavior, where identities were checked only when the turn ended.

## 中文摘要

### 升级决策

**谁需要升级：**运行 agent turn、且在 turn 进行中进程树发生变化、进程 id 可能被无关进程复用的用户。

**解决了什么：**[#560](https://github.com/foolzzz/looper/pull/560) 在每次刷新 turn 进程树之前拒绝被复用的进程身份。此前启动时间已变化的 pid 只在 turn 结束时才被排除，中间的刷新可能接纳替代进程的子树或进程组，结束 turn 时就可能向其发送信号。

**是否有破坏性变更：**否。API、配置、prompt 和 Tool 声明均未改变。

**如何验证：**运行 `looper --version` 核对版本为 2.13.97。

**贡献者：**维护者 @foolzzz 提交 [#560](https://github.com/foolzzz/looper/pull/560)；本次 patch release 无社区贡献。

```bash
looper --version   # looper 2.13.97
```

### 行为变化与入口

- **进程身份检查（[#560](https://github.com/foolzzz/looper/pull/560)）：**`looper/agents/proc_tree.py` 中的 `TurnTree.refresh` 现在先用最新进程表调用 `_reused`，再展开进程树，并从记住的进程组中去掉被排除的 pid。启动时间与首次观察不一致的 pid 记入新增的 `_excluded` 集合，在本 turn 剩余时间内一直被排除。`TurnTree.track` 现在在 turn 开始时读取启动时间，使初始身份从一开始就存在。
- **无法证明的身份：**从未读到启动时间、或不在启动时间表中的 pid，只在该次观察中被排除，不会被赋予后来进程的启动时间。完全无法读取启动时间时，所有已见 pid 和 agent 自身的 pid 都被排除。已记录身份且已被回收的根进程仍拥有其存活的进程组。
- **turn 结束：**`TurnTree.end` 现在先刷新再计算排除集，而不是先排除再刷新。agent 自身 pid 没有身份时，`_end_all` 只对仍存活的子进程句柄发送 SIGTERM（超过宽限期后 SIGKILL），不会根据 pid 推断进程组。
- **不变：**身份已证实的进程仍照常结束；其他渠道、仪表盘和停止流程不变。
- **面向模型的变化：**prompt、Tool 声明和 Tool 结果均无变化。
- **测试：**`tests/test_proc_tree.py` 新增用例：跨刷新的身份复用、无法读取的身份、已回收的根进程，以及仅用句柄的回退。[#560](https://github.com/foolzzz/looper/pull/560) 报告新增测试 163 行、生产代码 32 行。

### 升级与回退

v2.13.97 发布后重跑 `install.sh`。无需迁移数据，无需改配置。回退到 v2.13.96 会恢复之前仅在 turn 结束时检查身份的行为。
