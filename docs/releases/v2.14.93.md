# Looper v2.14.93

This is the patch release v2.14.93, a hotfix line in which each merged change ships at once. It ships the one change merged since v2.14.92: a TTADK sign-in check that could not finish no longer refuses runs, and `looper doctor` waits for it ([#1126](https://github.com/foolzzz/looper/pull/1126)).

## Release Decision

**Who should upgrade:** Operators who launch Agent Profiles through TTADK (`ttadk-codex`, `ttadk-cursor-agent`), especially on a slow network, or who rely on `looper doctor` to confirm TTADK is signed in. Everyone else can stay.

**What this release solves:** A TTADK sign-in check that timed out read as `check_failed` and a launch refused it, so a slow network refused runs although the operator was signed in. Separately, `looper doctor` read the cached, non-waiting value, so it could print a warning ("checking") and exit 0 while TTADK was signed out. [#1126](https://github.com/foolzzz/looper/pull/1126) makes a launch refuse only when TTADK is not found, not signed in, or the wrong tool; an unfinished check lets the run start and is logged as a warning. The doctor now waits for the check. It closes #1095.

**Breaking changes:** No. No schema change and no API change.

**How to verify:** Check the installed version. With TTADK signed in, run `looper doctor`: the TTADK line reports the real sign-in state instead of "checking". A TTADK run no longer fails to start only because the sign-in check timed out.

**Contributors:** Maintainer @foolzzz authored [#1126](https://github.com/foolzzz/looper/pull/1126); no community contribution was included in this release.

```bash
looper --version   # looper 2.14.93
```

## Behavior changes

- **A launch refuses only a definite TTADK problem** (`looper/agents/agent_settings.py`, `looper/agents/runtimes/ttadk.py`). `TtadkProblem` gains `blocks_launch`, true for `not_found`, `not_signed_in` and `wrong_tool`. The Agent Profile login check refuses a launch only for those. For `check_failed` (the sign-in check timed out or could not finish) the run starts and a warning is logged ("TTADK sign-in check could not finish ... starting run"); if TTADK cannot sign in, the run itself fails. The `checking` state, which the launch wait does not return, is unchanged.
- **Launch record note** (`looper/agents/runtimes/ttadk.py`, `agent_settings.py`). When a TTADK launch started on a cached `check_failed` result, the launch record gains `ttadk_check` ("could not finish (check_failed)"). It reads the cache and does not probe again. The record is run metadata for audit, not sent to the model.
- **Doctor waits for the TTADK check** (`looper/agents/self_check.py`). `check_ttadk` takes `wait` (default true), and the `looper doctor` run (`run_checks`) waits for the sign-in check, so it reports the result and its exit status reflects it. The server's startup check and the HTTP status poll (`ttadk_check`) keep the non-waiting read.
- **Unchanged:** how the sign-in check runs, the other TTADK problems, other runtimes, the schema, API fields, the dashboard.
- **Documentation and tests.** Updated `tests/test_ttadk_runtime.py`, `tests/test_ttadk_cursor_agent.py`, `tests/test_ttadk_doctor.py`.
- **Model-visible changes:** None. No tool description, prompt text or tool output changes. The only new text is a log line, the launch-record note and the doctor output.

## 中文摘要

本版本是 patch release v2.14.93（热修线，每个合并的改动立即发布）。自 v2.14.92 以来只合并了一项改动：TTADK 登录检查未能完成时不再拒绝运行，`looper doctor` 会等待该检查（[#1126](https://github.com/foolzzz/looper/pull/1126)）。

### 升级决策

**谁需要升级：**通过 TTADK 启动 Agent Profile（`ttadk-codex`、`ttadk-cursor-agent`）的运维人员，尤其是网络较慢时，或依赖 `looper doctor` 确认 TTADK 已登录的情况。其他人可不升级。

**解决了什么：**TTADK 登录检查超时会被读作 `check_failed`，启动因此被拒绝，所以网络慢时即使已登录也无法运行。另外，`looper doctor` 读取的是缓存的非等待值，TTADK 未登录时可能打印警告（“checking”）却以 0 退出。[#1126](https://github.com/foolzzz/looper/pull/1126) 让启动只在 TTADK 未找到、未登录或工具不对时拒绝；检查未完成时运行照常开始并记录警告。doctor 现在会等待该检查。关闭 #1095。

**是否有破坏性变更：**否。无结构变更，无 API 变更。

**如何验证：**核对版本为 2.14.93。TTADK 已登录时运行 `looper doctor`：TTADK 一行报告真实的登录状态，而不是 “checking”。TTADK 运行不再仅因登录检查超时而无法启动。

**贡献者：**维护者 @foolzzz 提交 [#1126](https://github.com/foolzzz/looper/pull/1126)；本版本无社区贡献。

### 行为变化与入口

- **启动只拒绝明确的 TTADK 问题**（`looper/agents/agent_settings.py`、`looper/agents/runtimes/ttadk.py`）。`TtadkProblem` 新增 `blocks_launch`，对 `not_found`、`not_signed_in`、`wrong_tool` 为真。Agent Profile 登录检查只对这些情况拒绝启动。对 `check_failed`（登录检查超时或未能完成），运行照常开始并记录警告（“TTADK sign-in check could not finish ... starting run”）；若 TTADK 确实无法登录，运行本身会失败。启动等待不会返回的 `checking` 状态不变。
- **启动记录备注**（`looper/agents/runtimes/ttadk.py`、`agent_settings.py`）。TTADK 启动基于缓存的 `check_failed` 结果时，启动记录新增 `ttadk_check`（“could not finish (check_failed)”）。它只读缓存，不再探测。该记录是审计用的运行元数据，不会发给模型。
- **doctor 等待 TTADK 检查**（`looper/agents/self_check.py`）。`check_ttadk` 新增 `wait`（默认为真），`looper doctor`（`run_checks`）会等待登录检查，因此报告结果且退出状态随之反映。服务器启动检查和 HTTP 状态轮询（`ttadk_check`）仍使用非等待读取。
- **不变：**登录检查的运行方式、其他 TTADK 问题、其他运行时、数据库结构、API 字段、仪表盘。
- **文档与测试。**更新 `tests/test_ttadk_runtime.py`、`tests/test_ttadk_cursor_agent.py`、`tests/test_ttadk_doctor.py`。
- **面向模型的变化：**无。工具描述、提示文本和工具输出均不变。新增的文本只有一行日志、启动记录备注和 doctor 输出。
