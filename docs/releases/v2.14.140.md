# Looper v2.14.140

This is the patch release v2.14.140, a hotfix line in which each merged change ships at once. It documents one change: [#1247](https://github.com/foolzzz/looper/pull/1247) (gate notices carry the question; records stay readable).

## Release Decision

**Who should upgrade:** Operators who answer user gates from the web chat, because the gate notice now carries the question and how to answer. Operators who read the Process record, TTADK failure text, the startup self-check or journal text also see changes. Everyone else gets no visible change.

**What this release solves:** [#1247](https://github.com/foolzzz/looper/pull/1247) makes a user gate post its number, question and answer form into the web chat, keeps the first lines of TTADK failure text, lists reviews newest first in the Process record with a pointer to the task page, keeps non-ASCII journal text readable, keeps file names in SUPERVISE activity lines, reports a still-running TTADK check as pending in the self-check, and makes Cursor's effort refusal say it takes no effort level.

**Breaking changes:** No. There is no migration and no API removal. The text some Planner messages carry changes (see Behavior changes). The bridge boundary is unchanged: upgrade to v2.13.165 first if the installation is older.

**How to verify:** Check the installed version.

```bash
looper --version   # looper 2.14.140
```

**Contributors:** Maintainer @foolzzz authored [#1247](https://github.com/foolzzz/looper/pull/1247); no community contribution was included in this release.

## Upgrading

The bridge boundary is unchanged: an installation older than v2.13.165 must upgrade to v2.13.165 first (upgrade to v2.13.165 first) and be started once; see the Upgrading section of the v2.14.0 release for the steps and rollback. An installation on v2.14.0 to v2.14.139 upgrades directly. There is no schema change.

## Behavior changes

- **A web-chat gate notice carries the question** ([#1247](https://github.com/foolzzz/looper/pull/1247), `looper/agents/gate_commands.py`, `looper/agents/tiers/manager.py`, `looper/agents/tiers/planner.py`). When the Planner opens a user gate it reports a `gate_opened` progress message. For a web thread the Manager numbers the gate in that chat's command snapshot (keeping earlier numbers), and posts the number, the task title, the step, the question (the agenda questions joined, clipped to 500 characters, or the topic) and the reply form `/gate <number> <answer>`. Telegram and Lark ignore this message because the gate courier posts the discussion there.
- **An opened gate no longer reports plain progress.** The Planner now reports progress after opening only a wait; opening a gate reports the gate notice instead.
- **TTADK failure text keeps its head** (`looper/agents/runtimes/ttadk.py`). After redaction, a diagnostic over 1000 characters keeps its first 400 and its last characters with an omission marker, instead of only the last 1000.
- **The Process record lists reviews newest first** (`looper/agents/workflow_reporting.py`). The omission marker now says the full record is on the task page.
- **Journal text stays readable.** The Planner's review round, late review, adjudication, verification, escalation and profile fallback journal entries are written with non-ASCII characters intact instead of `\u` escapes.
- **SUPERVISE activity lines keep file names** (`looper/agents/tiers/planner.py`). The step's work directory prefix is removed from each activity summary and long lines keep both ends within 160 characters.
- **The self-check reports a running TTADK check as pending** (`looper/agents/self_check.py`, `looper/agents/http_server.py`). A TTADK check still in progress gives status pending instead of warning. A refreshed self-check only keeps the stored result for a pending check whose detail is "Startup check in progress"; other pending checks are re-read.
- **Cursor's effort refusal** (`looper/agents/profile_registry.py`). A non-empty effort for a runtime with no effort levels is refused with "takes no effort level; leave effort empty".
- **Unchanged:** reply contracts, decisions and dispatching, the Worker, Reviewer and Manager prompts, and the storage format of journal entries.
- **Model-visible changes:** Yes. The Planner's journal text carries non-ASCII characters literally, and its SUPERVISE activity lines drop the work directory prefix and keep both ends of long lines ([#1247](https://github.com/foolzzz/looper/pull/1247)). TTADK failure text retained in a run and its activity has a different clip. No protocol prompt changes.

### 升级决策

**谁需要升级：**在 Web 聊天中回答用户关卡的运维者，因为关卡通知现在带有问题和回答方式；阅读过程记录、TTADK 失败文本、启动自检或日志文本的运维者也会看到变化。其他人没有可见变化。

**解决了什么：**[#1247](https://github.com/foolzzz/looper/pull/1247) 让用户关卡把编号、问题和回答格式发到 Web 聊天；保留 TTADK 失败文本的开头；过程记录按新到旧列出评审并指向任务页面；日志中的非 ASCII 文本保持可读；SUPERVISE 活动行保留文件名；自检把仍在运行的 TTADK 检查报告为待定；Cursor 的 effort 拒绝信息说明它不接受 effort 级别。

**是否有破坏性变更：**否。没有迁移，没有移除 API。部分 Planner 消息的文本有变化（见下文）。桥接边界不变：早于 v2.13.165 的安装须先升级到 v2.13.165。

**如何验证：**核对版本为 2.14.140。

**贡献者：**维护者 @foolzzz 提交 [#1247](https://github.com/foolzzz/looper/pull/1247)；本版本无社区贡献。

```bash
looper --version   # looper 2.14.140
```

### 升级

桥接边界不变：早于 v2.13.165 的安装必须先升级到 v2.13.165 并启动一次（upgrade to v2.13.165 first 即先升级到 v2.13.165），步骤与回退见 v2.14.0 发布说明的升级一节。v2.14.0 至 v2.14.139 上的安装可直接升级。没有结构变更。

### 行为变化与入口

- **Web 聊天的关卡通知带有问题**（[#1247](https://github.com/foolzzz/looper/pull/1247)，`looper/agents/gate_commands.py`、`looper/agents/tiers/manager.py`、`looper/agents/tiers/planner.py`）。Planner 打开用户关卡时上报 `gate_opened` 进度消息。对 Web 会话，Manager 在该聊天的命令快照中给关卡编号（保留此前的编号），并发送编号、任务标题、步骤、问题（议程问题拼接后截断到 500 字符，或主题）以及回答格式 `/gate <编号> <回答>`。Telegram 和 Lark 忽略该消息，因为这两处由关卡信使发送讨论。
- **打开关卡不再上报普通进度。**Planner 现在只在打开等待步骤后上报进度；打开关卡改为上报关卡通知。
- **TTADK 失败文本保留开头**（`looper/agents/runtimes/ttadk.py`）。脱敏后超过 1000 字符的诊断保留前 400 字符和末尾部分并加省略标记，而不是只保留最后 1000 字符。
- **过程记录按新到旧列出评审**（`looper/agents/workflow_reporting.py`）。省略标记现在说明完整记录在任务页面。
- **日志文本保持可读。**Planner 的评审轮次、迟到评审、裁决、验证、升级和配置回退日志条目写入时保留非 ASCII 字符，不再是 `\u` 转义。
- **SUPERVISE 活动行保留文件名**（`looper/agents/tiers/planner.py`）。每条活动摘要去掉步骤工作目录前缀，长行在 160 字符内保留首尾。
- **自检把运行中的 TTADK 检查报告为待定**（`looper/agents/self_check.py`、`looper/agents/http_server.py`）。仍在进行的 TTADK 检查状态为待定而非警告。刷新自检时，只有详情为“Startup check in progress”的待定检查才保留已存结果，其他待定检查会重新读取。
- **Cursor 的 effort 拒绝**（`looper/agents/profile_registry.py`）。对没有 effort 级别的运行时设置非空 effort 会被拒绝，并提示不接受 effort 级别、请留空。
- **不变：**回复契约、决策与派发，Worker、Reviewer 和 Manager 提示词，以及日志条目的存储格式。
- **面向模型的变化：**有。Planner 的日志文本直接带有非 ASCII 字符，其 SUPERVISE 活动行去掉工作目录前缀并在长行中保留首尾（[#1247](https://github.com/foolzzz/looper/pull/1247)）。运行及其活动中保留的 TTADK 失败文本裁剪方式不同。协议提示词没有变化。
