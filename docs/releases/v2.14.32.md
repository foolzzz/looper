# Looper v2.14.32

This is the patch release v2.14.32, a hotfix line in which each merged change ships at once. It ships the one change merged since v2.14.31: a TTADK run that ends without a result now keeps a redacted stderr tail, and the dashboard names the TTADK launcher ([#947](https://github.com/foolzzz/looper/pull/947)).

## Release Decision

**Who should upgrade:** Anyone who runs agents through the TTADK launcher and needs to see why a run ended without a result, or who wants the launcher shown in Agent Profiles. Installations that use only native runtimes see no change in error text.

**What this release solves:** [#947](https://github.com/foolzzz/looper/pull/947) fixes the P1 findings of issue #945 on the TTADK launcher: a TTADK run that ended without a result gave no diagnostics, and the dashboard did not tell a TTADK runtime from a native one.

**Breaking changes:** No. No API, default or existing behavior is removed, and there is no database migration. The `launcher` field the dashboard reads is optional.

**How to verify:** Check the installed version.

**Contributors:** Maintainer @foolzzz authored [#947](https://github.com/foolzzz/looper/pull/947); no community contribution was included in this release.

```bash
looper --version   # looper 2.14.32
```

## Upgrading

The bridge boundary is unchanged: an installation older than v2.13.165 must upgrade to v2.13.165 first and be started once; see the Upgrading section of the v2.14.0 release for the steps and rollback. An installation on v2.14.0 to v2.14.31 upgrades directly. This release adds no migration.

## Behavior changes

- **TTADK runs that end without a result keep their stderr ([#947](https://github.com/foolzzz/looper/pull/947)).** This applies only when the runtime's exit code is not reliable (the TTADK launcher) and the turn produced no result event.
  - **Tail.** A new `error_tail` helper in `looper/agents/runtimes/ttadk.py` redacts credentials and keeps the last 1,000 characters of stderr. A per-turn process now returns its stderr on the turn result (`ResidentTurn.stderr`) when it ended without a result; with a result the field is empty.
  - **Worker.** The failure error becomes "<runtime> through TTADK ended without a result: <tail>" when there is a tail, an `error` activity with the same text is recorded when the run has a parent task, and the returned `stderr` is the redacted tail. A native runtime keeps "exited with code N" and the 500-character `stderr`.
  - **Planner.** The same error is recorded as an `error` activity and used as the turn's error in place of "exited before finishing the turn (exit code N)". If the session could not be resumed, the same text is appended to that error.
  - **Manager.** The tail is appended to the "no reply", "could not be resumed" and Chinese "没有返回内容" errors when the process exited.
  - **Dashboard.** The Agent Profiles page titles a runtime whose `launcher` is `ttadk` as `<name> (launcher: ttadk)`, so two runtimes of the same type are told apart. The `Runtime` type gains the optional `launcher` field, which the registry already sends.
- **Model-visible changes:** None. No prompt, tool or message text given to a model changes; the new text appears in errors, run records and activity.

桥接边界不变：早于 v2.13.165 的安装必须先升级到 v2.13.165 并启动一次（upgrade to v2.13.165 first 即先升级到 v2.13.165），步骤与回退见 v2.14.0 发布说明的升级一节。v2.14.0 至 v2.14.31 上的安装可直接升级。本版本没有迁移。

### 行为变化与入口

- **没有结果就结束的 TTADK 运行保留 stderr（[#947](https://github.com/foolzzz/looper/pull/947)）。**只在运行时的退出码不可靠（TTADK 启动器）且该轮没有结果事件时生效。
  - **尾部。**`looper/agents/runtimes/ttadk.py` 新增 `error_tail`，先脱敏再保留 stderr 最后 1000 个字符。逐轮进程在没有结果就结束时，通过 `ResidentTurn.stderr` 返回 stderr；有结果时该字段为空。
  - **Worker。**失败错误变为 “<runtime> through TTADK ended without a result: <尾部>”（有尾部时）；运行有父任务时记录同文本的 `error` 活动；返回的 `stderr` 为脱敏尾部。原生运行时仍是 “exited with code N” 和 500 字符的 `stderr`。
  - **Planner。**同样的错误记为 `error` 活动，并取代 “exited before finishing the turn (exit code N)” 作为该轮错误；会话无法恢复时，同一文本追加到该错误之后。
  - **Manager。**进程已退出时，尾部追加到 “no reply”、“could not be resumed” 和中文 “没有返回内容” 错误之后。
  - **控制台。**Agent Profiles 页面把 `launcher` 为 `ttadk` 的运行时标为 `<name> (launcher: ttadk)`，使同类型的两个运行时可以区分。`Runtime` 类型新增可选的 `launcher` 字段，注册表本来就会发送它。
- **面向模型的变化：**无。给模型的提示词、工具或消息文本都不变；新文本只出现在错误、运行记录和活动中。
