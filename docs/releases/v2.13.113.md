# Looper v2.13.113

## Release Decision

**Who should upgrade:** No one needs this release for its behavior. It adds test coverage only; the `looper` package, the dashboard and the example scripts are unchanged.

**What this release solves:** [#614](https://github.com/foolzzz/looper/pull/614) adds browser probes that reproduce the reported delayed configuration-download failure, so the dashboard's configuration export can be checked against the bytes the browser saves.

**Breaking changes:** No. No route, configuration, request field or stored data format changed.

**How to verify:** Check the installed version.

**Contributors:** Maintainer @foolzzz authored [#614](https://github.com/foolzzz/looper/pull/614); no community contribution was included in this patch release.

```bash
looper --version   # looper 2.13.113
```

## Behavior changes

- **Runtime behavior:** None. [#614](https://github.com/foolzzz/looper/pull/614) changes one file, the new `tests/test_configuration_download_browser.py`; no production file is touched.
- **What the new tests do:** they build the dashboard (`npm run build` in `web/`), serve the built files from a local server, and drive the Settings transfer page in headless Chromium through Playwright with the API answered by synthetic fixtures (no live API). The tests are marked `installed`, and skip when Playwright or Chromium is missing. The file states that these are reproduction probes, not evidence of a fixed defect.
- **Cases covered:** `test_configuration_download_readback` exports a configuration with one and with 5000 catalog entries, answering immediately and after 6.5 seconds (when the browser's transient user activation has expired), then checks that a download starts, that the saved bytes equal the compact UTF-8 JSON of the document and parse back to it, that the button is enabled again and that no alert shows. `test_unsuccessful_export_has_no_download_and_retry_works` covers a cancelled request (leaving the page), a network failure and an invalid JSON response: no download or stale file is produced, and a retry then downloads normally.
- **Model-visible changes:** None. No tool declaration, prompt or API route changed.
- **Tests:** [#614](https://github.com/foolzzz/looper/pull/614) reports added lines: tests 160, production 0 (fixtures excluded).

## Upgrade and rollback

Re-run `install.sh` once v2.13.113 is published. No data migration and no configuration change. Rolling back to v2.13.112 removes only the added test file.

No new optional capability activation is introduced in this release.
