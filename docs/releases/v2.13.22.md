# Looper v2.13.22

## Release Decision

**Who should upgrade:** Dashboard users of the Gates page, and API clients that call the gates list with `limit` or `offset`. Everyone else sees no change.

**What this release solves:** [#358](https://github.com/foolzzz/looper/pull/358) fixes the review follow-ups of #319. The Gates list refresh no longer drops rows past the first 200, the All view no longer offers Answer on gates of completed tasks, the list layout no longer overflows at 1024px, and a non-ASCII digit in `limit` or `offset` is refused with 400 instead of failing with 500.

**Breaking changes:** No. No CLI command, configuration key or database schema changed. A gates list request with a non-ASCII digit such as `²` in `limit` or `offset` now returns 400; it returned 500 before.

**How to verify:** Check the installed version.

**Contributors:** Maintainer @foolzzz authored [#358](https://github.com/foolzzz/looper/pull/358); no community contribution was included in this patch release.

```bash
looper --version   # looper 2.13.22
```

## Behavior changes

- **Gates list refresh keeps every loaded row:** the 10-second refresh re-reads all loaded rows, in requests of at most 200 and following on by offset until the loaded count or the total is reached. Before, it read at most 200 rows, so rows loaded past that with "Show more" were truncated, along with their drafts. "Show more" still adds 50 rows (`web/src/pages/gates.tsx`).
- **No Answer on completed tasks:** the Answer button needs `task.group !== "completed"` as well as a gate waiting on the user, so the All view no longer offers Answer on an unclosed gate of a completed task (`web/src/pages/gates.tsx`).
- **Layout breakpoint:** the seven-column grid of the header and the rows moves from the `lg` to the `xl` breakpoint, so it no longer overflows at 1024px; below `xl` the rows stack. Long task names are clamped to two lines, with the full name in the link's `title` (`web/src/pages/gates.tsx`).
- **Non-ASCII digits are refused:** the gates list query accepts `limit` and `offset` only when they are ASCII digits; a value such as `²` now returns 400 with the existing messages, not 500 (`looper/agents/gate_service.py`).
- **Tests:** `tests/test_gates_list_db.py` adds `²` for `limit` and `offset` to the refused queries. `web/src/pages/gates.test.tsx` adds a test for no Answer on a completed task's gate and one that a refresh keeps all 250 loaded rows, and moves the layout test to `xl`.
- **Deferred, not fixed here:** the PR defers three flaky tests that pass alone and have no reproducible root cause (`test_dsh_installed_run_without_platform_bridge[False-reviewer/worker]`, `test_schema_applies_twice_with_column_and_constraint`, `test_rpc_failures_preserve_accumulated_model_usage[fast_rejected]`); they stay open in #319.
- **Model-visible changes:** None. No prompt, tool schema or tool result changed. The changes belong to the dashboard and to the HTTP API's input check.

## Upgrade and rollback

Re-run `install.sh` once v2.13.22 is published. There is no schema or configuration change. Rolling back to v2.13.21 is safe; the Gates page then truncates its refresh again.

## Optional Capability Activation & Use

No new optional capability activation is introduced in this release.

**谁需要升级：**使用 Gates 页面的 Dashboard 用户，以及调用 gates 列表并传 `limit` 或 `offset` 的 API 客户端。其他人没有变化。

**是否有破坏性变更：**无。CLI、配置项、数据库 schema 均未变化。gates 列表请求的 `limit` 或 `offset` 含 `²` 等非 ASCII 数字时现在返回 400，此前为 500。

### 行为变化与入口

- Gates 列表刷新保留所有已加载的行：每 10 秒的刷新重新读取全部已加载的行，每次请求最多 200 行，按 offset 继续读取，直到达到已加载数量或总数。此前最多读取 200 行，用“Show more”加载到 200 行之后的行会被截断，其草稿也随之丢失。“Show more”仍每次增加 50 行（`web/src/pages/gates.tsx`）。
- 已完成任务不再提供 Answer：Answer 按钮除了 gate 在等待用户之外，还要求 `task.group !== "completed"`，All 视图不再对已完成任务的未关闭 gate 提供 Answer（`web/src/pages/gates.tsx`）。
- 布局断点：表头与各行的七列网格从 `lg` 断点移到 `xl`，在 1024px 不再溢出；小于 `xl` 时各行堆叠。过长的任务名限制为两行，完整名称放在链接的 `title` 中（`web/src/pages/gates.tsx`）。
- 拒绝非 ASCII 数字：gates 列表查询只接受 ASCII 数字的 `limit` 和 `offset`；`²` 之类的值现在返回 400（沿用原有提示），不再返回 500（`looper/agents/gate_service.py`）。
- 测试：`tests/test_gates_list_db.py` 把 `limit`、`offset` 取 `²` 加入被拒绝的查询。`web/src/pages/gates.test.tsx` 新增已完成任务的 gate 不提供 Answer、刷新保留全部 250 个已加载行两个测试，并把布局测试改到 `xl`。
- 延后未修：PR 延后了三个单独运行即通过、无法复现根因的不稳定测试（`test_dsh_installed_run_without_platform_bridge[False-reviewer/worker]`、`test_schema_applies_twice_with_column_and_constraint`、`test_rpc_failures_preserve_accumulated_model_usage[fast_rejected]`），仍在 #319 跟踪。
- 面向模型的变化：无。提示词、工具 schema、工具结果均无变化。改动属于 Dashboard 与 HTTP API 的输入校验。
